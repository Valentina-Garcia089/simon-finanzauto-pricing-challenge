# Prueba Técnica — Analista de Data y Procesos (Simón Movilidad & Finanzauto)

Solución integral en **Python** para el análisis de inventario de subastas, benchmarking de mercado, perfilación de compradores y estrategia de pricing dinámico.

## Estructura del Repositorio

- `data/raw/`: Dataset original de subastas (`inventario_subastas_.csv`).
- `data/external/`: Fuentes externas abiertas (RUNT / referencia de mercado).
- `data/processed/`: Dataset limpio y enriquecido con métricas financieras.
- `notebooks/`: Análisis exploratorio y validación paso a paso.
- `src/`: Scripts modulares de ETL, métricas de negocio y modelo de pricing dinámico.
- `app/dashboard.py`: Tablero interactivo en Streamlit.
- `docs/`: Presentación ejecutiva en PDF para el Comité Directivo.
